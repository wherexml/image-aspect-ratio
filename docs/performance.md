# Mobile performance delivery

The 2026-10-27 release preserves the calculator, analytics and visual design while changing first-render delivery.

- `vite.config.ts` enables TanStack Start's `server.build.inlineCss`. The root imports CSS as a side effect so Start owns the route stylesheet manifest. Development remains normal Vite CSS handling.
- `src/styles.css` excludes unused `components/ui`, tests and Markdown from Tailwind candidate discovery. No product route currently imports the component library. When introducing a UI component, include its classes in the source scan and verify its rendered states.
- `src/font-faces.css` is generated by `scripts/build-font-subsets.py`. Common Latin UI glyphs are embedded through Vite `?inline` URLs. Complementary unicode ranges load the unchanged original font for all other original glyphs. The original OFL licenses remain in `public/fonts`; `ui-subsets.json` records hashes and coverage. The original font README records the earlier acquisition/preload implementation; this document defines current delivery.
- Regenerate subsets only when needed, using a temporary Python environment with `fonttools[woff]==4.60.2`, then run `python scripts/build-font-subsets.py`. Normal application builds require no Python. Generation retains original timestamps for deterministic hashes, original glyph geometry/advances, variable axes and OpenType layout features.
- Remove no font family, weight, original fallback file or license. Do not change `font-display` or add font preloads without checking for duplicate downloads and visual shifts.
- The unused React Query provider and QueryClient initialization have been removed; no page consumes queries/mutations. The optional root context type remains compatible with callers passing a client. Add a provider only when a real query feature needs it.
- GA4 and GEO loading, collection, QA flags and privacy behavior are unchanged. There is no Lighthouse/user-agent detection, hidden content, interaction-only analytics trigger or artificial wait to improve a score.

Tradeoff: initial HTML includes CSS and common font bytes and is larger, while eliminating first-render CSS/font request chains. SPA navigation retains the existing styles; static CSS and original font fallbacks remain available. Do not assume a fixed score under all network/CPU conditions.

Release evidence and repeatable HTTP/browser steps: `verification/mobile-performance-20261027/README.md`.
